# Welcome to Citograph

Your citation and research workspace is ready.

**To open it:** use the **Citograph** desktop shortcut or double-click **Start Citograph.cmd** in this folder. The launcher selects the newest packaged build automatically. You can also open **release/win-unpacked/Citograph.exe** directly; this main location now contains version **1.4.0**.

**To install it:** run **release/Citograph Setup 1.4.0.exe**. Choose your installation folder; the installer can create a desktop shortcut.

Start with the marked sample library or click **Remove samples** to begin with your own research. Import a PubMed `.nbib`, `.bib`, `.ris`, `.json`, or EndNote `.xml` file using **Import library**.

Try **Research atlas** to explore connections, **Evidence matrix** to compare papers, and **Writing studio** to draft and export a manuscript with citations. Attach your PDFs from the paper inspector to read and annotate them.

Your data stays in your local library. Make a complete backup in **Settings** before moving to another computer.

Read **README.md** for all features, data locations, development instructions, and current limits. **Citograph-preview.png** and **Citograph-preview-dark.png** show the interface.

**Microsoft Word:** save and close all Word windows, double-click **Install Word Add-in.cmd**, then reopen Word. Use the **Citograph** tab for citations, bibliographies, and the document's traveling library. Read **word-addin/WORD_GUIDE.md**. The desktop app is version 1.4.0; its Word document engine is version 1.4.

**Style maker:** open **Style Studio**. Python is bundled. Build or edit a style, preview it, save a version, then inspect Word and apply the saved style. Read **STYLE_STUDIO_GUIDE.md**. EndNote .ens import currently creates a guided draft that needs review; it does not decode all original formatting rules.

**EndNote documents:** open your saved .docx in Word, then use **Settings → EndNote document migration** in Citograph. Review sources, select a style and create a new copy. Read **ENDNOTE_MIGRATION_GUIDE.md**.
